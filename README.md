# Arushi AI Voice & App Assistant 🤖🇮🇳

An Indian multilingual AI Voice and Assistant application powered by Google Gemini with live tool calling, on-device app launching, calling, and WhatsApp integration.

## 📱 Features
- **Auto Multi-Language Voice**: Hindi, English, Hinglish, Marathi, Bengali, Gujarati, Tamil, Telugu, Punjabi, Malayalam, and more.
- **WhatsApp Integration**: Instant `"WhatsApp kholo"` / `"Open WhatsApp"` voice command.
- **Direct Calling & Contacts**: Look up contacts and initiate phone calls naturally.
- **Gemini Intelligence**: Complete Q&A, chat, and reasoning in all Indian regional languages.
- **In-App API Key Configuration**: Add or update your Google Gemini API key easily inside the app settings.

## 🚀 Automated APK Generation via GitHub Actions
This repository includes an automated CI/CD pipeline (`.github/workflows/build-apk.yml`) that builds an APK automatically whenever you push code or trigger a build.

### How to download the APK from GitHub:
1. Go to the **Actions** tab in this GitHub repository.
2. Select the latest workflow run named **"Build and Release Android APK"**.
3. Under the **Artifacts** section at the bottom, click **`Arushi-AI-Voice-Assistant-APK`** to download your ready-to-install APK.
